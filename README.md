# short-drama-script — 短剧剧本标准化写作 Skill

> OpenClaw 生态下的短剧全链路编剧自动化工具，一键将小说/IP/故事改编为标准格式的横屏/竖屏短剧剧本。

## ✨ 核心能力

| 能力 | 输出内容 |
|------|---------|
| 剧本改编 | 自动将长篇小说/IP/故事梗概改编为符合短剧生产标准的剧本 |
| 故事梗概 | 提炼核心剧情、核心冲突、核心爽点，适配短视频传播逻辑 |
| 人物小传 | 生成主要角色的人设、性格、背景、成长线（1+3+N 矩阵） |
| 分集大纲 | 标准化分集大纲，每集卡点明确 |
| 逐集正文 | 标准场景头格式的逐集剧本，动作/台词/镜头提示 |
| 卡点标注 | 四级卡点体系（一卡/二卡/三卡/日常卡点） |

## 🎯 触发指令

用户说以下关键词即可自动触发：
- 编写短剧剧本、写短剧脚本
- 小说改短剧、IP改剧本
- 生成故事梗概、人物小传、分集大纲
- 给我写XX类型的短剧剧本（甜宠/爽文/悬疑/古装/都市等）
- 设计卡点、短剧节奏

## 🔄 8步标准工作流

```
Step 0: 确认输入（小说/大纲/口头描述 + 集数 + 画幅 + 题材）
    ↓
Step 1: 提取核心骨架（一句话故事 + 核心冲突 + 主题 + 爽点清单）
    ↓
Step 2: 角色矩阵映射（1个主角 + 3个配角 + N个功能角色）
    ↓
Step 3: 情节裁剪与重组（删支线、合并角色、拆设定）
    ↓
Step 4: 识别情绪爆点（欺辱→反击、身份反转、一招秒杀等）
    ↓
Step 5: 规划全局节奏（3-5-3 模型：建立→升级→收束）
    ↓
Step 6: 设计四级卡点（一卡/二卡/三卡/日常卡点）
    ↓
Step 7: 逐集撰写（标准场景头格式）
    ↓
Step 8: 质量自检（8项量化检查，≥7达标才输出）
```

详见 [CORE-SKILL.md](CORE-SKILL.md)。

| **女频甜宠**（重生/甜宠/穿书/大女主） | 前世惨死→重生觉醒 | 身份反转、CP暧昧、虐渣 | 《将军请入怀》《左手惊天下》《狂躁症》 |

## 📝 使用示例

### 示例1：小说改短剧
**输入：** `帮我把《XXX》这本小说改成60集的竖屏短剧剧本`

**输出：**
1. 故事核心梗概 + 核心爽点提炼
2. 主要人物小传（1+3+N 矩阵）
3. 60集分集大纲，每集卡点明确
4. 逐集正文剧本，标准场景头格式
5. 每集的卡点标注

### 示例2：快速生成短剧大纲
**输入：** `给我生成一个都市神豪类的短剧大纲，30集`

**输出：**
1. 核心设定：主角身份、金手指、核心冲突
2. 人物小传：3-5个主要角色
3. 30集分集大纲
4. 开头3集完整剧本示例
