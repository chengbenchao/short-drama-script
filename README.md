# short-drama-script 短剧剧本生成Skill
> OpenClaw生态下的短剧全链路编剧自动化工具，一键将小说/IP/故事改编为标准格式的横屏/竖屏短剧剧本。

## ✨ 核心能力
| 能力 | 输出内容 |
|------|---------|
| 剧本改编 | 自动将长篇小说/IP/故事梗概改编为符合短剧生产标准的剧本 |
| 故事梗概 | 提炼核心剧情、核心冲突、核心爽点，适配短视频传播逻辑 |
| 人物小传 | 生成主要角色的人设、性格、背景、成长线，符合短剧人物设定逻辑 |
| 分集大纲 | 生成标准化分集大纲，每集卡点明确，30秒钩子+1分钟冲突+结尾反转留悬念 |
| 逐集正文 | 输出标准场景头格式的逐集剧本，包含动作、台词、镜头提示 |
| 卡点标注 | 自动标注每集的爽点、泪点、反转点、钩子位置，适配短视频算法推荐 |

## 🎯 触发指令
用户说以下关键词即可自动触发对应功能：
- 编写短剧剧本、写短剧脚本
- 小说改短剧、IP改剧本
- 生成故事梗概、人物小传、分集大纲
- 给我写XX类型的短剧剧本（甜宠/爽文/悬疑/古装/都市等）

## 📋 内置规范
所有输出严格遵循短剧行业生产标准：
- [剧本格式规范](references/format-spec.md)：统一场景头、动作、台词格式，可直接导入后期生产工具
- [编剧公式文档](references/formulas.md)：内置20+爆款短剧编剧公式，涵盖爽文、甜宠、悬疑、古装等主流类型
- [剧本模板](assets/template.md)：标准化输出模板，直接可用
- [剧本数据库索引](references/script-database.md)：内置100+爆款短剧样本参考

## 🚀 安装使用
### 方式1：通过ClawHub安装（推荐）
```bash
clawhub install short-drama-script
```

### 方式2：手动安装
1. 克隆仓库到OpenClaw技能目录
```bash
git clone https://github.com/chengbenchao/short-drama-script.git ~/.openclaw/skills/short-drama-script
```
2. 重启OpenClaw服务即可自动加载

## 📝 使用示例
### 示例1：小说改短剧
用户输入：`帮我把《开局给女帝送猪》这本小说改成100集的竖屏短剧剧本`
输出：
1. 故事核心梗概+核心爽点提炼
2. 主要人物小传（女帝、男主、反派等）
3. 100集分集大纲，每集卡点明确
4. 逐集正文剧本，标准场景头格式
5. 每集的卡点标注（钩子位置、爽点位置、反转位置）

### 示例2：快速生成短剧大纲
用户输入：`给我生成一个都市神豪类的短剧大纲，30集`
输出：
1. 核心设定：主角身份、金手指、核心冲突
2. 人物小传：3-5个主要角色设定
3. 30集分集大纲，每集包含核心剧情、钩子、爽点
4. 开头3集的完整剧本示例
