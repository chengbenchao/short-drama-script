# 短剧剧本标准模板（含第一集写作规范）

> 本模板定义短剧改编的标准输出结构。每次生成剧本，必须包含以下三个部分。

---

## 一、基础信息（必选）

| 项目 | 内容 |
|------|------|
| 剧名 | 《XXX》 |
| 备用名 | 《XXX》《XXX》 |
| 类型 | 男频/女频·都市/古装·异能/甜宠/悬疑 |
| 集数 | 60集（竖屏） |
| 单集时长 | 1.5-2分钟 |
| 单集字数 | 1100-1200字 |
| 场景头格式 | 点号空格版 `1.1 地点 时间 内/外` |

---

## 二、故事梗概（200-300字）

**写作公式：** `[主角身份] + [意外事件] + [获得金手指] + [核心目标] + [最大阻碍]`

**示例：**
> 职场精英张泽因醉酒被一只神秘猫妖强行交换身体，变成了一只名为"大花"的虎斑猫。为了恢复人身，他必须利用猫妖的超能力（兽灵印记、摄魂眼、超强感官）通过做好事积攒"业力"。在都市的角落里，大花救下突发心脏病的老人、协助警察破案、惩治饭店鼠怪、感知病人厄运。在悠闲的撸猫生活中，他逐渐揭开了都市隐藏的神秘世界，并在这个过程中收获了跨物种的羁绊，最终发现猫妖交换身体背后隐藏着更大的阴谋。

**检查点：**
- [ ] 是否包含主角身份和核心动机？
- [ ] 是否点明金手指/超能力？
- [ ] 是否暗示主线悬念或最终 BOSS？
- [ ] 字数是否在 200-300 字之间？

---

## 三、人物小传（1+3+N 矩阵）

### 核心主角（1个）
```
姓名：XXX
身份：[前世身份] → [现世身份]
外貌：[关键特征，如"银灰条纹虎斑猫，眼神犀利如人"]
性格：[2-3个核心形容词，如"外表高冷傲娇，内心吐槽役"]
金手指：[具体能力列表]
目标：[短期目标] + [长期目标/最终目标]
```

### 重要配角（3个）
```
姓名：XXX
身份：[与主角关系]
性格：[核心特征]
功能：[推动剧情/武力担当/情感纽带等]
```
（重复 3 次，每个配角独立一段）

### 功能角色（N个）
- 列出 2-3 个关键功能角色，一句话描述即可

**检查点：**
- [ ] 主角是否有 want ≠ need 的内在冲突？
- [ ] 每个配角是否有标志特征（遮住名字能认出）？
- [ ] 功能角色是否不超过 3 句话？

## 四、第一集剧本写作规范

### 核心要求（全剧统一标准）
1. **字数**：≥1100 字（目标 1100-1200 字）
2. **场景数**：≤4 个场景（含 4 个）
3. **开头**：前 3 秒必须有视觉冲击或信息悬念（张力十足）
4. **结尾**：必须卡在反转/高潮/悬念时刻，让观众必须追下一集

### 第一集结构模板

```
### 第 1 集 / [标题]

1.1 [地点] [时间] 内/外
人物：[列出所有出场角色]

△[开场动作：极端情境/视觉冲击/反常事件]

[角色 A]（情绪）：[台词]

△[冲突升级/悬念加深]

[角色 B]（情绪）：[台词]

△[金手指触发/主角觉醒/核心事件发生]

1.2 [地点] [时间] 内/外
人物：[角色]

△[适应新身份/接受现实/首次使用能力]

[主角]（OS）：[内心独白，展示人性与兽性的冲突]

△[能力测试/初步成功]

1.3 [地点] [时间] 内/外
人物：[主角 + 配角/危机对象]

△[第一个小危机出现]

△[主角面临选择：救人 vs 自保]

[主角]（OS）：[内心挣扎，展示价值观]

△[主角决定介入，展示人性光辉]

1.4 [地点] [时间] 内/外
人物：[主角 + 危机对象 + 潜在威胁/反派线索]

△[危机解决过程，使用金手指]

△[意外收获：业力松动/能力解锁/发现新线索]

[主角]（OS）：[对未来的展望/新的疑问]

△[结尾反转：新危机出现/反派现身/更大阴谋浮出水面]

【本集卡点：[用一句话概括悬念，如"猫妖站在对面楼顶，拨通了神秘电话"]】

【本集完】
```

### 开头张力公式（三选一）

| 类型 | 公式 | 示例 |
|------|------|------|
| 极端情境 | `[主角处于生死/绝望边缘] + [意外事件发生]` | 跳河瞬间被白光击中 |
| 信息悬念 | `[反常现象] + [主角困惑]` | 暴雨中黑猫开口说人话 |
| 身份反转 | `[主角以为 A] → [实际是 B]` | 以为醉酒做梦，醒来变成猫 |

### 结尾卡点公式（三选一）

| 类型 | 公式 | 示例 |
|------|------|------|
| 反派现身 | `[主角刚松口气] → [更大威胁出现]` | 猫妖站在楼顶看着主角 |
| 能力失控 | `[主角使用能力] → [意外后果]` | 摄魂眼定住人后出现黑云 |
| 新危机 | `[解决旧问题] → [新问题爆发]` | 老人得救但药瓶掉入下水道 |


### 场景转换规范（全剧适用）

**核心原则：** 场景之间必须有逻辑或情绪关联，禁止生硬跳跃。

**常用转换手法（至少选一种用于每两个场景之间）：**

| 转换类型 | 公式 | 示例 |
|----------|------|------|
| 动作衔接 | [场景A动作未完成] → [场景B动作延续] | 主角跃入水中 → 在水底睁开眼睛 |
| 声音桥梁 | [场景A的声音延续到场景B] | 电话铃声在A响起 → B中主角接起同一电话 |
| 物件传递 | [场景A的物件] → [场景B出现同一物件] | 主角看着照片 → 镜头切换到照片中的地点 |
| 情绪延续 | [场景A的情绪] → [场景B延续同种情绪] | 主角愤怒离开 → 下一场景主角在别处仍在发泄 |
| 时间跳跃 | [明确的时间标注] + [状态对比] | "三天后" → 主角从狼狈变为整洁 |
| 悬念承接 | [场景A提出悬念] → [场景B解答或加深] | "那是什么？" → "那是……" |

**禁止项：**
- ❌ 两个场景之间没有任何关联元素
- ❌ 突然切换到完全不相关的人物或地点
- ❌ 场景转换超过 3 秒没有任何承接线索

**写作技巧：**
- 场景A的最后一句台词或最后一个动作，应包含通向场景B的"钩子"
- 场景B的第一个动作或第一句台词，应回应场景A的"钩子"
- 使用【特写】标注关键转换物件或细节

### 字数控制技巧
- 每个场景约 250-300 字
- 动作描写（△）占 30%
- 对白占 40%
- 内心独白（OS）占 20%
- 特写/卡点占 10%
- **严禁**：长篇环境描写、冗余背景交代、说教式台词

### 对白写作规则
- **要**：短句、带情绪、有潜台词、口语化
- **不要**：书面语、平铺直叙、直白说透、超过 3 行

**金句公式：** `对比/反转 + 情感共鸣 + 记忆点 = 爆款金句`
