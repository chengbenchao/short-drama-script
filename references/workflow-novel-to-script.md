# 小说→短剧剧本 标准工作流

> 本流程定义从小说/故事/IP 改编为竖屏/横屏短剧剧本的完整操作步骤。
> 适用于所有题材类型（男频爽文、女频甜宠、搞笑反套路、横屏正剧）。

---

## 总览：8 步工作流

```
Step 1: 读原著，提取核心骨架
    ↓
Step 2: 角色矩阵映射（1+3+N）
    ↓
Step 3: 情节裁剪与重组
    ↓
Step 4: 识别情绪爆点
    ↓
Step 5: 规划全局节奏（3-5-3 模型）
    ↓
Step 6: 设计四级卡点
    ↓
Step 7: 逐集撰写（标准场景头格式）
    ↓
Step 8: 质量自检（8项量化检查）
```

---

## Step 1：读原著，提取核心骨架

从小说中抽出四个要素，压缩到一页纸内：

| 提取项 | 格式 | 说明 |
|--------|------|------|
| **一句话故事** | `谁 + 做了什么 + 结果如何` | 用一句话概括全剧 |
| **核心冲突** | `人vs人 / 人vs己 / 人vs环境` | 短剧只能有一条主线 |
| **主题** | `一句话回答"这部剧到底在讲什么"` | 例：绝境中的坚守、被背叛后的逆袭 |
| **爽点/泪点清单** | `5-8个最能引发情绪波动的场景` | 从原著中标注，后续分配给各集 |

**输出格式示例：**

```
一句话故事：现代人穿越成扶不起的阿斗，靠系统加点+现代科技改写蜀汉命运。
核心冲突：刘禅 vs 世家利益集团（人vs人）+ 历史必然性（人vs环境）
主题：明知历史走向，能否逆天改写？
爽点清单：
  1. 开局杀吕蒙（冷开场）
  2. 朝堂打脸李严（智力碾压）
  3. 校场接惊马（武力展示）
  4. 灌钢法造刀（科技碾压）
  5. 五千破两万（战术碾压）
```

---

## Step 2：角色矩阵映射（1+3+N）

将原著角色压缩为短剧可承载的规模：

| 原著角色 | 剧本处理 | 规则 |
|----------|----------|------|
| 主角/双主角 | → **1个核心主角** | want ≠ need，必须有内在冲突 |
| 重要对手/盟友/CP | → **3个重要配角** | 每人一个标志特征，遮住名字能认出 |
| 功能性角色 | → **N个功能角色** | 完成任务即退，最多3句话 |
| 其他所有角色 | **合并或删除** | 短剧承载不了群像，必须砍 |

**人物小传模板：**

```
完整版（策划文档用）：
  姓名 + 身份 + 性格 + 背景 + 核心动机(want≠need) + 结局走向

精简版（竖屏短剧常用）：
  姓名 + 身份 + 外貌 + 性格 + 目标/目的
```

---

## Step 3：情节裁剪与重组

| 原著内容 | 处理方式 |
|----------|----------|
| 开篇 3-5 章 | → 前 3 集：**保留最强钩子，删铺垫** |
| 中间大量支线 | → 合并到 3 个配角身上，其余砍掉 |
| 高潮段落 | → 对应一卡/二卡/三卡位置 |
| 世界观/设定说明 | → 拆成对白和动作展示，**不要旁白解说** |
| 心理描写 | → 转为 os 内心独白或面部表情+动作 |
| 环境描写 | → 转为 ▲ 画面动作或【特写】标注 |

---

## Step 4：识别情绪爆点

从原著中找以下类型场景，标注为"必用爆点"：

| 爆点类型 | 说明 | 适用题材 |
|----------|------|----------|
| 被欺辱→反击 | 最经典爽点 | 男频/女频通用 |
| 身份反转 | 废柴→天才、穷小子→首富 | 男频 |
| 背叛→复仇 | 被最信任的人出卖后反击 | 男频/女频 |
| 绝境→觉醒 | 濒死时刻获得能力/领悟 | 男频 |
| CP暧昧/壁咚/强吻 | 情感张力最高点 | 女频 |
| 一招秒杀 | 实力碾压 | 男频 |
| 沙雕/反套路行为 | 搞笑操作出意外好结果 | 搞笑类 |

**分配规则：** 这些爆点必须安排在 **第1集开场 + 每集结尾卡点 + 一卡/二卡/三卡**。

---

## Step 5：规划全局节奏（3-5-3 模型）

### 12集标准版

| 阶段 | 集数 | 核心任务 | 关键 |
|------|------|----------|------|
| 前 3 集 | 1-3 | 建立人设 + 核心冲突 + 第一个高潮 | 钩子要炸 |
| 中 5 集 | 4-8 | 升级矛盾 + 配角登场 + 情感深化 | 节奏要稳 |
| 后 3 集 | 9-11 | 终极对决 + 主题升华 + 留续作空间 | 高潮要猛 |
| 尾声 | 12 | 收束 + 悬念 | 故事完但故事未完 |

### 60集竖屏版（比例缩放）

| 阶段 | 集数 | 核心任务 |
|------|------|----------|
| 建立 | 1-18 | 人设+冲突+金手指觉醒 |
| 升级 | 19-48 | 矛盾递进+配角+情感 |
| 收束 | 49-60 | 终极对决+主题升华+留口 |

### 单集结构：微型三幕

```
开场钩子（10-15秒）→ 建置+激励事件
正文冲突（60-90秒）→ 对抗升级
卡点收尾（15-30秒）→ 悬念/反转/情绪爆点
```

- **钩子**：前3秒必须有视觉冲击或信息悬念
- **冲突**：至少一层外部冲突 + 一层内部冲突
- **卡点**：意外事件 + 情绪冲击 + 未解悬念

---

## Step 6：设计四级卡点

| 级别 | 位置 | 功能 | 公式 |
|------|------|------|------|
| 一卡 | 第 1/3 处 | 第一个大反转 | 意外事件 + 情绪冲击 + 未解悬念 |
| 二卡 | 第 2/3 处 | 终极对决 | 正面对抗 + 胜负未定 + 情感代价 |
| 三卡 | 收尾前 | 主题升华 | 价值观碰撞 + 主角抉择 |
| 日常卡点 | 每集结尾 | 引导下一集 | 新危机/新信息/新人物出现 |

**竖屏 60 集卡点间距：** 每 10 集一卡（第10/20/30/40/50/60集）

---

## Step 7：逐集撰写

### 格式规范速查

| 元素 | 写法 |
|------|------|
| 集标题 | `第 1 集 /XXXX字` |
| 场景头 | 8种格式选一种，全剧统一（详见 format-spec.md） |
| 画面动作 | `▲ 动作描写` 或 `△ 动作描写`（全剧统一一种） |
| 对白 | `角色名（情绪）：台词` |
| 内心独白 | `角色 os：内容` 或 `角色（OS）：内容`（全剧统一） |
| 画外音 | `角色ov：内容` 或 `角色（VO）：内容`（全剧统一） |
| 特写 | `【特写】关键画面细节` |
| 角色字幕 | `【字幕：角色名丨身份】` |
| 集末标注 | `【本集完】` 或 `【本集卡点：XXX】` |

### 场景头格式（8选1）

| 格式 | 示例 | 适用 |
|------|------|------|
| 完整版 | `场景-1\n地点：秋瓷城城墙 - 日 -（外景）` | 横屏正剧 |
| 简化版 | `1-1\n地点：咖啡厅 - 日 -（内景）` | 竖屏主流 |
| 极简版 | `女儿国，日，内` | 动态漫/AI剧 |
| 空格版 | `赵家庭院 夜 外` | 古风漫剧 |
| 冒号版 | `场景：大姚皇宫 外 夜` | 女频古装/都市战神 |
| 场字版 | `场1-1 定远候府院子-日-外` | 穿书/沙雕爽文 |
| **逗号版** | `1-1 日，内，侯府` | **女频古装穿越** |
| **点号空格版** | `1.1峡谷 夜 外` | **男频历史/争霸** |

### 每集字数
- 竖屏短剧：600-1200 字/集
- 横屏短剧：1200-2500 字/集

## Step 8：质量自检（8项量化检查）

输出前逐项打勾，**至少 7/8 达标才输出**：

```
[ ] 前3集钩子：第1集前3秒有视觉冲击或信息悬念？每集开场有"让人停不下来"的钩子？
[ ] 每集悬念：每集结尾有明确卡点标注？是否包含"新危机/新信息/新人物"三要素之一？
[ ] 主角弧光：主角从A状态→B状态的改变是否在分集大纲中体现？至少3个关键转折点？
[ ] 配角记忆点：遮住角色名后，能否通过台词风格/动作特征分出谁在说话？每个配角至少1个标志特征？
[ ] 对白口语化：随机抽10句对白，大声读出来像人说话吗？≥8句自然即合格
[ ] 金句数量：全文是否有 2-3 句能被记住、被引用的话？（对比/反转+情感共鸣+记忆点）
[ ] 卡点位置：一卡在第1/3处、二卡在第2/3处、三卡在收尾前？间距是否均匀？
[ ] 格式合规：场景头格式是否全剧统一？▲/△是否只选一种？OS/OV写法是否全剧统一？
```

## 对白「三要三不要」

| 要 | 不要 |
|---|---|
| 口语化（像人说的话） | 书面语（像文章念出来的） |
| 有情绪（带温度带态度） | 平铺直叙（像AI生成的） |
| 有潜台词（水面之下有东西） | 直白说透（把话说死了） |

**金句公式：** `对比/反转 + 情感共鸣 + 记忆点 = 爆款金句`

## 题材差异化要点

### 男频爽文类

| 维度 | 策略 |
|------|------|
| 第1集钩子 | 主角被欺辱/背叛/绝境 → 金手指激活（10秒内完成） |
| 卡点类型 | 打脸反转、实力碾压、一招秒杀 |
| ▲ 动作密度 | 高（80-300处/60集） |
| OS 使用 | 适度（5-15处/60集） |
| 【特写】 | 高频（系统面板、数值、转账记录） |

### 女频类

| 维度 | 策略 |
|------|------|
| 第1集钩子 | 前世惨死/被背叛/穿书醒来 → 重生/觉醒（情感冲击优先） |
| 卡点类型 | 身份反转、CP暧昧/壁咚、虐渣打脸 |
| ▲ 动作密度 | 中低（0-100处/60集） |
| OS 使用 | 高频（情感内心是女频核心驱动力） |
| 【特写】 | 面部微表情、手部动作、信物细节 |

### 搞笑/反套路类

| 维度 | 策略 |
|------|------|
| 第1集钩子 | 反常行为/沙雕操作 → 意外好结果 |
| 卡点类型 | 反向操作成功、吐槽名场面 |
| 卡点频率 | 每 5-8 集一大卡（笑点密集） |
| 【音效】/【视觉特效】 | 必用 |

## 实操 checklist

当用户给到小说/故事时，按以下顺序确认：

1. [ ] 拿到原著（docx/pdf/链接/直接粘贴）
2. [ ] 确认目标集数（12/30/60/自定义）
3. [ ] 确认横屏还是竖屏
4. [ ] 确认题材类型（男频/女频/搞笑/正剧）
5. [ ] 执行 Step 1-4（提取+映射+裁剪+爆点）
6. [ ] 输出"基础信息+故事梗概+人物小传+分集大纲"给用户确认
7. [ ] 用户确认后，执行 Step 5-7（规划+卡点+逐集撰写）
8. [ ] 执行 Step 8 质量自检，≥7/8 达标后输出
