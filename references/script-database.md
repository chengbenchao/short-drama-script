### 竖屏 vs 横屏格式差异

| 维度 | 竖屏 | 横屏 |
|------|------|------|
| 场景编号 | 偏好 `X-X`（极简） | 偏好 `场景-X`（完整） |
| 单集场景数 | 2-3个 | 3-5个 |
| 【特写】使用 | 高频（手机屏幕等） | 低频 |
| 单集字数 | 600-1200字 | 1200-2500字 |
| 卡点频率 | 每10集左右一卡 | 按3-5-3节奏分布 |
| ▲ 动作密度 | 50-300处/60集 | 密集 |
| OS 使用 | 普遍（内心独白驱动） | 适度 |
