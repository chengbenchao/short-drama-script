# 《寻宝全世界》专属创作规则

> 本文件定义《寻宝全世界》项目的固定设定和创作要求，写作时必须严格遵守。

---

## 一、核心固定设定（创作严格遵循，禁止OOC）

### 固定故事梗概

28岁前华尔街投行分析师叶天因团队操作失误被迫背锅，被全金融行业拉黑，身负十万美金债务的他又遭遇相恋五年女友的背叛，绝望之下跳河轻生被渔民救下，意外被神秘白光击中获得透视异能：可看穿所有物品内部结构、识别古董年代与价值、吸收古董散发出的灵气强化自身体质。绝境翻盘的叶天放弃重返金融圈的想法，投身门槛极低的仓储拍卖行业，凭借异能在旁人弃如敝履的"垃圾仓库"中屡屡挖出天价藏品，打脸歧视挑衅的同行，一步步成为身家亿万的顶级收藏家，同时也因挖出的古董牵扯进跨国走私旧案，被黑白两道同时盯上，逐步揭开异能背后的惊天秘密。

### 固定人物小传

#### ① 叶天（核心主角）
- **年龄**：28岁
- **身份**：前华尔街精英 → 仓储拍卖寻宝人
- **性格**：智商高心思缜密，冷静果决，面对挑衅反击干脆
- **背景**：被行业封杀负债跳河，得透视异能
- **金手指**：透视异能（看穿物品内部结构、识别古董年代与价值、吸收古董灵气强化体质）
- **目标**：靠寻宝还清债务，改写落魄人生
- **走向**：从落魄负债到身家亿万的顶级收藏家，揭开异能背后的惊天秘密

#### ② 韦尔奇（核心反派）
- **年龄**：36岁
- **身份**：资深职业挖宝人
- **性格**：势利贪婪，极端种族歧视，嚣张跋扈
- **功能**：前期核心反派，多次当众羞辱入行的叶天，被叶天多次打脸后怀恨在心，勾结黑帮报复

#### ③ 贝蒂（重要配角）
- **年龄**：26岁
- **身份**：叶天的邻居，职业健身教练
- **性格**：飒爽正直，直爽利落
- **功能**：多次帮叶天赶跑催债混混，对充满神秘感的叶天抱有好感，武力担当+情感纽带

#### ④ 杰森（重要配角）
- **年龄**：30岁
- **身份**：二手店老板，混迹旧货行业十年
- **性格**：爽朗直接，为人仗义
- **功能**：精通估值与销售渠道，见识到叶天的寻宝能力后主动提出合作，是叶天的左膀右臂

## 二、内容创作要求

| 项目 | 要求 |
|------|------|
| 单集字数 | 控制在 1100-1200 字左右 |
| 开头 | 张力十足、有悬念钩子 |
| 结尾 | 必须卡在反转/悬念点，吸引观众继续观看 |
| 镜头场景 | 每集控制在 4 个以内（包含 4 个） |
| 剧情 | 紧扣主线，不重要支线或无关内容可适当删减 |
| 逻辑 | 逻辑合理、内容流畅 |
| 戏剧冲突 | 适当通过对话推进剧情、增加戏剧冲突，提升可看性 |
