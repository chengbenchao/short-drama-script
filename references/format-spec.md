# 短剧标准剧本格式规范

---

## 0. 通用剧本写作格式规则（强制执行）

### 1. 镜号格式

- 统一为：`X-Y 场景名 时间 内/外`
- 时间表述：**仅可使用 日/夜/傍晚 三种**，禁止使用上午/下午等其他时间词

### 2. 画面描述规则

- 所有场景环境、人物动作、神态、道具等**可视化内容**统一以 `△` 开头标注
- 要求：**精简无冗余、逻辑顺畅**
- 仅保留可直接影视化的核心信息
- **禁止**添加非可视化抒情修饰内容

### 3. 特殊标注规则

| 类型 | 格式 | 说明 |
|------|------|------|
| 闪回 | `△闪回：[具体画面内容]` | 直接呈现闪回画面，无额外标点或括号修饰 |
| 特效 | `△特效：[具体特效画面]` | 直接呈现特效呈现效果 |

### 4. 对白格式规则

- 所有角色对白**单独成行**，禁止与 `△` 标注的画面内容混用同一行
- 常规对白格式：`角色名：（对应动作/神态简洁描述）对白内容`
- **每句对白必须搭配对应的简单动作/神态描述**

### 5. 画外音格式

- `角色名ov：（对应动作/场景说明）对白内容`
- 短信、通知等文字类信息，直接在 `△` 标注的画面中明确呈现具体内容

## 1. 集标题与场景编号

### 集标题

```markdown
第 1 集 /XXXX字（原著第 1 集）
```

标注本集字数和对应原著集数（如有）。竖屏短剧通常 600-1200 字/集，横屏短剧 1200-2500 字/集。

### 场景编号

多种格式均可，全剧统一一种：

#### 格式A：完整版（`场景-X`）
```markdown
场景-1
地点： 秋瓷城城墙 - 日 -（外景）
人物： 顾长安、老妪、百姓若干
```
适用：横屏正剧、正式剧本

#### 格式B：简化版（`X-X`）
```markdown
1-1
地点： 咖啡厅 - 日 -（内景）
人物： 叶东、刘薇薇、系统
```
适用：竖屏主流短剧

#### 格式C：逗号版
```markdown
1-1 日，内，侯府
```
适用：古装穿越短剧（女频常用），如《将军请入怀》

#### 格式D：点号空格版
```markdown
1.1峡谷 夜 外
人物： 刘禅、吕蒙、赵云
```
适用：男频历史/争霸短剧，如《穿越刘禅》

#### 格式E：极简版
```markdown
女儿国，日，内
人物： 唐僧、女儿国国王
```
适用：动态漫/AI生成剧

#### 格式F：空格版
```markdown
赵家庭院 夜 外
人物： 赵老爷、管家
```
适用：古风漫剧

#### 格式G：冒号版
```markdown
场景：大姚皇宫 外 夜
人物： 皇帝、妃子
```
适用：女频古装/都市战神

**通用规则：**
- 地点尽量具体
- 时间只写 日/夜/黄昏/黎明
- 人物列出本场景所有出场角色
- 竖屏短剧每集建议 2-3 个场景

## 2. 画面动作（Action）

用 `▲` 或 `△` 符号标记所有画面描述、动作、环境描写。

两种符号均可使用，全剧统一一种即可。主流标杆剧本中：
- `▲` 用于：《鉴宝金瞳》《墟界师尊》《孤城》《女神返利》
- `△` 用于：《裙下之臣》《天相局中局》

```
▲城墙之上，百姓跪地恳求投降。
▲白发老妪走到顾长安跟前，老泪纵横。
▲黄沙散去，三百铁骑疾驰来到秋瓷城下。
```

**规则：**
- 每条 ▲ 描述一个独立画面或动作
- 用现在时，简洁有力
- 不写角色心理，心理走 os
- 不写台词，台词走对白格式

## 3. 对白（Dialogue）

```
角色名（情绪/语气）：台词内容
```

**情绪标注示例：**
- `（哀求）` `（冷笑）` `（沉声）` `（坚定）` `（惊恐）` `（平静）` `（暴怒）`

**无情绪标注时省略括号：**
```
顾长安：不降。
```

**规则：**
- 角色名后跟冒号
- 情绪用括号包裹，紧跟角色名
- 每段对白独立一行
- 对白口语化，避免书面语

## 4. 内心独白（OS）

两种写法均可，全剧统一一种：

```markdown
# 写法A：小写无括号（SKILL标准版）
角色 os：独白内容

# 写法B：大写括号（剧组常用版）
角色（OS）：独白内容
```

**规则：**
- OS 表示内心独白（off-screen thought）
- 角色在画面内，声音仅在角色脑海中
- 与对白格式区分，不要混用

## 4b. 画外音（OV/VO）

两种写法均可，全剧统一一种：

```markdown
# 写法A：小写无括号（SKILL标准版）
角色ov：台词内容
系统ov：叮！检测到宿主，绑定成功！

# 写法B：大写括号（剧组常用版）
角色（VO）：台词内容
系统（VO）：叮！检测到宿主，绑定成功！
```

**OS 与 OV/VO 的区别：**

| 标注 | 含义 | 使用场景 |
|------|------|----------|
| os / （OS） | 内心独白 | 角色在画面内，声音仅在角色脑海中 |
| ov/ov / （VO） | 画外音 | 角色不在画面内但声音可闻，如隔壁房间、远处传来、系统提示音等 |

**规则：**
- 用于系统提示音、电话另一头、隔壁房间传话等
- 与 OS 严格区分，不可混用
- VO 和 OV 含义相同，VO 更接近影视工业术语（Voice Over）

## 5. 角色字幕（Character Lower Third）

在角色首次出场或需要强调身份时插入：

```
【字幕：顾长安丨秋瓷城最后守将】
【字幕：蛮军首领丨金发碧眼】
```

**格式：**
- 方括号包裹
- `角色名丨身份描述`，用竖线分隔
- 放在该角色出场后的动作描写之后

## 6. 卡点标注（Hook / Cliffhanger）

每集结尾必须标注本集卡点：

```
【本集卡点：唐旗不倒，顾长安继续坚守】
【一卡大反转：火种觉醒，顾长安斩杀两千敌寇】
【二卡终极对决：顾长安击败扶商，桃花剑客陨落】
```

**规则：**
- 方括号包裹
- 用简短有力的短语概括悬念/反转
- 多卡剧集可标注"一卡""二卡""三卡"
- 卡点公式：意外事件 + 情绪冲击 + 未解悬念

## 7. 【特写】标注

```
【特写】系统出现在叶东面前。
【特写】叶东手机收到一笔80元的转账。
【特写】叶东手机屏幕：支付500元，余额变为1000元。
```

**使用场景：**
- 手机屏幕内容（转账记录、聊天记录、系统界面）
- 关键道具细节
- 角色面部微表情
- 对竖屏短剧尤其重要——竖屏画面窄，必须明确告知摄影哪些细节需要特写

**规则：**
- 方括号包裹
- 描述要具体（"手机屏幕：支付500元"而非"手机屏幕"）
- 通常放在相关动作描写之后

## 8. 卡点标注简化写法

竖屏短剧常用简化版：
```markdown
【本集完】
```

完整卡点描述版（推荐用于策划/审核文档）：
```markdown
【本集卡点：叶东激活系统，反手一巴掌打脸情敌】
【一卡大反转：火种觉醒，顾长安斩杀两千敌寇】
【二卡终极对决：顾长安击败扶商，桃花剑客陨落】
```

两种写法均可，全剧统一。【本集完】更简洁，适合快速制作；【本集卡点：XXX】更详细，便于审核和排期。

## 9. 横屏短剧完整示例

```markdown
第 1 集 孤城不降

场景 -1
地点： 秋瓷城城墙 - 日 -（外景）
人物： 顾长安、老妪、白发老人、百姓若干

▲城墙之上，百姓跪地恳求投降。
▲白发老妪走到顾长安跟前，老泪纵横。

老妪（哀求）：长安，投降吧，然后离开秋瓷城，找个地方好好生活下去。

▲顾长安一脸坚定，摇头。

顾长安：不降。

顾长安 os：整整六十年，安西军无人投降，无人被俘。

顾长安（沉声）：奶奶，你觉得我要做这个懦夫吗？

▲人群中，白发老人嘶吼。

白发老人（激动）：你不一样！你勇猛无敌！蛮国曾多次劝降你，承诺投降便给你一阶官职！如今大唐遗忘了这座城，你牺牲掉也没有意义啊！

▲顾长安没有回应，转身朝城墙方向走去。

顾长安（背对众人）：此城已经坚守了六十年，坚守一辈子又何妨？只要我还在，这面唐旗就不会倒下。

【字幕：顾长安丨秋瓷城最后守将】

场景 -2
地点： 城墙 - 日 -（外景）
人物： 顾长安、蛮军首领、蛮军士兵若干

▲顾长安在城墙检查各处守御器械。
▲远处传来怒吼，马匹奔腾声让地面剧烈震动。

顾长安 os：听这动静，大概三百敌军即将来袭。

▲黄沙散去，三百铁骑疾驰来到秋瓷城下。
▲蛮军抬头看见顾长安，眼中没有厌恶憎恨，只有敬佩与肃穆。

【字幕：蛮军首领丨金发碧眼】

蛮军首领（高喊）：登城！

【本集卡点：唐旗不倒，顾长安继续坚守】
```

## 10. 竖屏短剧完整示例（含特写、OV 标注）

```markdown
第 1 集 /1200字

1-1
地点： 咖啡厅 - 日 -（内景）
人物： 叶东、刘薇薇、张志刚、系统

▲叶东和刘薇薇对坐。

刘薇薇：叶东，让你爸妈在山城全款买一套房子，写我一个人的名字，再买一辆50万的车……

叶东（哀求）：我爸妈就是普通工人，这几年我天天馒头加白菜，兼职赚的钱也都花你身上了，怎么可能在山城买得起房子！

刘薇薇（不为所动）：还有，我俩结婚以后你父母不和我们生活在一起。

叶东（着急）：我爸妈就我一个儿子，我怎么能抛弃他们呢？

▲刘薇薇冷漠。

叶东（嘶吼）：刘薇薇，为什么？你明知道你提出的条件，我根本不可能完成！

刘薇薇（冷淡，高傲）：为什么？我好不容易从农村出来，我再也不想回到那种小地方生活了！

张志刚ov：说得好！

▲西装革履的张志刚走出，刘薇薇起身依偎过去。

张志刚（得意）：刚哥！

叶东（愤恨）：原来你早就和张志刚搞到一起去了！

系统ov：叮！检测到合适的宿主，绑定成功！请问宿主是否要激活系统！

【特写】系统面板出现在叶东面前。

叶东 os（激动）：激活！

系统ov：叮！激活之前考验宿主的强者之心，请宿主给他们一人一耳光，再把咖啡泼到绿茶脸上！

刘薇薇（轻蔑）：叶东，没钱就别学别人谈恋爱！

张志刚（讥讽）：我家的酒楼和几千万资产，你拿什么和我比？

叶东 os：几年的感情说没就没了，难道真的只有钱才是真的吗？

▲叶东毫不犹豫，眼神冷了下来，给了张志刚一巴掌。

【本集卡点：叶东激活系统，反手一巴掌打脸情敌】
```

## 10. 格式元素速查表

| 元素 | 写法 | 说明 |
|------|------|------|
| 集标题 | `第 1 集 /XXXX字（原著第 1 集）` | 标注字数和原著对应 |
| 场景编号 | `场景-1` 或 `1-1` | 两者均可，全剧统一 |
| 画面动作 | `▲ 描写` | 每条一个独立画面 |
| 对白 | `角色（情绪）：台词` | 情绪可省略 |
| 内心独白 | `角色 os：内容` | 角色在画面内的心声 |
| 画外音 | `角色ov：内容` | 角色不在画面内，声音可闻 |
| 特写 | `【特写】描写` | 关键细节镜头，竖屏必用 |
| 角色字幕 | `【字幕：名丨身份】` | 首次出场或身份强调 |
| 卡点 | `【本集卡点：XXX】` | 每集结尾悬念 |
| 一卡/二卡/三卡 | `【一卡大反转：XXX】` | 关键节点大卡点标注 |
